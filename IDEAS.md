# Gradient Native — Ідеї та дорожня карта (Roadmap)

Цей документ зібраний за результатами аудиту та брейншторму розвитку **Gradient Native** (Rust `gradient-core` + WinUI 3 + SwiftUI).

---

## Випущено в `0.4.0`

- [x] **Push-події замість polling кожні 2 секунди**: стрімінг NDJSON-подій (`job`, `process`, `instance`, `log`) з `gradient-core` для миттєвих прогрес-барів, живих логів та зменшення навантаження на CPU/диск.
- [x] **Фікс вікна Microsoft OAuth у WinUI**: адаптивний розмір `WebView2` і збільшені `ContentDialogMaxWidth` / `ContentDialogMaxHeight`, щоб форма входу не обрізалась.
- [x] **Discord Rich Presence**: додано `.large_image("launcher")` у `app-lib` для відображення іконки лаунчера.

---

## 1. Кілер-фічі (чим Gradient виділятиметься)

- [ ] **Crash Doctor (розумний аналізатор збоїв)**
  Автоматичний розбір crash report / `latest.log` після падіння Minecraft (`OutOfMemoryError`, несумісна Java, конфлікт залежностей, винний мод у стектрейсі) із кнопкою швидкої дії: *«Вимкнути мод X»*, *«Збільшити RAM»* або *«Залити лог на mclo.gs»*.
- [ ] **Mod Bisect (пошук зламаного мода бінарним пошуком)**
  Автоматичне ділення модів навпіл із перезапусками для швидкого пошуку мода, що викликає краш у великих збірках.
- [ ] **Оптимізація в 1 клік (FPS Boost Pack)**
  Кнопка при створенні або в налаштуваннях профілю, яка підтягує з Modrinth актуальні під версію гри й завантажувача моди оптимізації (наприклад, Sodium + Lithium + FerriteCore + ImmediatelyFast / Embeddium для Forge).
- [ ] **Синхронізація `options.txt` між профілями**
  Глобальний пресет налаштувань Minecraft (керування, FOV, чутливість миші, звук) на базі `synced_options` в `app-lib`, який автоматично застосовується до нових профілів.
- [ ] **Снапшоти профілю (точки відновлення)**
  Швидке збереження стану модів і конфігів перед оновленням збірки або додаванням нових модів із можливістю відкату в 1 клік.
- [ ] **Порівняння двох профілів (Profile Diff)**
  Перегляд різниці між двома профілями (відсутні моди, різні версії) — зручно для синхронізації з друзями перед грою на приватному сервері.
- [ ] **Розумне прибирання профілю**
  Пошук зайвих залежностей (orphaned libraries після видалення модів), дублікатів і файлів, несумісних із поточною версією гри.

## 2. Покращення щоденного UX та контенту

- [ ] **Покращені логи**: пошук по тексту, фільтри рівнів (`INFO` / `WARN` / `ERROR`), автопрокрутка вниз, очищення старих логів (`logs::delete_logs`) і завантаження на **mclo.gs** в 1 клік.
- [ ] **Живий статус серверів (Ping / MOTD / онлайн)**: іконка сервера, MOTD, пінг і кількість гравців у вкладці «Сервери» та на головній (на базі `async-minecraft-ping`, який уже є в `app-lib`).
- [ ] **Бібліотека скінів і плащі (Capes)**: окремий вибір плащів (`get_available_capes`), збереження кількох скінів і швидке перемикання (`get_available_skins`, `equip_skin`, `remove_custom_skin`).
- [ ] **Глобальна галерея скриншотів**: перегляд мініатюр з усіх профілів сіткою в одному місці, копіювання в буфер обміну та видалення.
- [ ] **Перенесення світів і автобекапи**: копіювання світу в інший профіль, перейменування/видалення/відновлення з бекапу, а також автобекап після виходу з гри в обрану папку (OneDrive / Google Drive / iCloud) з ротацією.
- [ ] **Живий індикатор RAM під час гри**: відображення поточного споживання ОЗП процесом Java (наприклад, `RAM: 3.1 / 6.0 ГБ`) у шапці запущеного профілю.
- [ ] **Командна палітра (`Ctrl+K` / `Cmd+K`)**: миттєвий запуск профілів, світів, серверів і навігація з клавіатури.
- [ ] **Розширені пер-профільні налаштування**: перевизначення JVM-аргументів, роздільної здатності, hooks (`pre_launch` / `wrapper` / `post_exit`), змінних середовища та зміна версії Minecraft / завантажувача в уже створеному профілі.
- [ ] **Повноцінний Markdown на macOS**: форматування заголовків, списків, коду та зображень у `ProjectDescription.swift` (аналогічно `ProjectMarkdown.cs` у WinUI).
- [ ] **Повноцінна інтеграція CurseForge**: введення `CURSEFORGE_API_KEY` у налаштуваннях замість env-змінної, вибір версій і пряме встановлення файлів/модпаків.
- [ ] **Акаунт Modrinth**: підключення входу через `mr_auth.rs` для приватних проєктів і синхронізації.
- [ ] **Поширення профілю друзям / гра без хостингу**: експорт компактного профілю або посилання `gradient-native://`, опція швидкого додавання `e4mc` / `World Host`.
- [ ] **Майстер першого запуску (Onboarding Wizard)**: швидке налаштування входу в акаунт, автопідбір Java + RAM та вибір стартового профілю («Чистий Minecraft + FPS» або модпак).
- [ ] **Детектор «шейдери без Iris / Oculus»**: попередження, якщо у профіль додано шейдери без потрібного шейдер-мода, із кнопкою встановлення в 1 клік.
- [ ] **Повноцінний Offline Mode («Без інтернету»)**: індикатор відсутності мережі та миттєвий запуск уже встановлених профілів без очікування мережевих таймаутів.
- [ ] **Історія змін профілю (Timeline / Audit Log)**: короткий журнал дій усередині профілю (додано/оновлено/видалено мод), щоб легко знаходити причину проблем.
- [ ] **Вкладка «Реплеї» (ReplayMod / Flashback)**: перегляд списку записаних реплеїв, розміру та швидкий експорт або відкриття папки.
- [ ] **Швидкий вхід на сервер із буфера обміну**: авторозпізнавання IP/домену сервера в буфері обміну з кнопкою «Вставити й підключитись».

## 3. Нативна інтеграція з ОС

- [ ] **Розумний Drag & Drop**: перетягування `.mrpack`, `.jar`, `.zip` (ресурспаки/шейдери/датапаки) і `.png` (скіни) прямо у вікно лаунчера.
- [ ] **Системний трей (Windows) / Menu Bar (macOS)**: швидкий запуск останніх профілів/світів і статус фонових завантажень без відкриття головного вікна.
- [ ] **Windows Jump List та macOS Dock Menu**: запуск улюбленого профілю через контекстне меню іконки в панелі завдань / Dock.
- [ ] **Системні сповіщення (Toast / Notification Center)**: повідомлення про завершення встановлення збірки або аварійне завершення гри, коли лаунчер згорнуто.

## 4. Платформи, довіра та дистрибуція

- [ ] **Офіційний підпис Windows без SmartScreen**: подача заявки у **SignPath Foundation** (безкоштовно для open-source) і підключення `signpath/github-action-submit-signing-request` у `.github/workflows/native-build.yml`.
- [ ] **Підпис і нотаризація macOS + Sparkle appcast**: налаштування секретів `MACOS_CERTIFICATE_*`, `MACOS_NOTARY_*`, `SPARKLE_*` для безперешкодного запуску без Gatekeeper і автооновлень.
- [ ] **Нативний клієнт для Linux (перспектива)**:
  - Рекомендований стек: **Rust + GTK4 + Libadwaita** (уникає проблем із `WebKitGTK` на NVIDIA/Wayland за рахунок **Microsoft Device Code Flow** у системному браузері).
  - Зберігання токенів через **Secret Service D-Bus** (`zbus` уже є в `app-lib`) + fallback.
  - Дистрибуція: **AppImage** (збірка на `ubuntu-22.04` для сумісності `glibc`) та **`.deb`**, обережно з пісочницею Flatpak (ламатиме системну Java, wrapper-утиліти на кшталт `gamemode`/`mangohud` та Discord IPC).
- [ ] **Лендинг-сторінка на GitHub Pages**: опис фіч, скриншоти WinUI/SwiftUI та кнопка завантаження останнього релізу під ОС користувача.
