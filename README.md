# Gradient Native

Копія Tauri-репозиторію з історією Git. Нативні клієнти використовують той самий Rust-код Minecraft-лаунчера через локальний процес `gradient-core`.

| Папка | Що всередині |
| --- | --- |
| `core/` | Оригінальний workspace з Tauri/Vue, ядро `packages/app-lib` і новий адаптер `apps/launcher-bridge`. |
| `winui/` | Нативна оболонка на C# та WinUI 3. |
| `swiftui/` | Нативна оболонка на SwiftUI для macOS 15 і новіших. |

Нативні оболонки підтримують бібліотеку, пошук профілів, обкладинку з останнього скриншота, Microsoft та офлайн-вхід, імпорт `.mrpack`, чергу, запуск, зупинку та живий лог. У вкладці **Контент** можна додати локальний мод `.jar`, переглянути встановлений контент, увімкнути, вимкнути або видалити доступні елементи. У вкладці **Світи** можна відкрити одиночний світ або створити його резервну копію. Кнопка **Оновити** перечитує дані з диска.

**Каталог Modrinth** одразу показує популярні модпаки. У ньому можна шукати публічні модпаки й моди, переглядати опис і вибирати версію. Модпаки можна фільтрувати за версією Minecraft і завантажувачем, а для модів ці значення беруться з вибраного профілю. Результати можна сортувати за завантаженнями, датою публікації або оновлення. Модпаки встановлюються через чергу, а для модів ядро підбирає потрібні залежності.

Кнопка **Відкрити посилання** приймає URL Modrinth і відкриває картку проєкту. Для виклику з іншого застосунку використовуйте `gradient-native://modpack/<id>`, `gradient-native://mod/<id>` або `gradient-native://version/<id>`. На Windows зареєструйте схему кнопкою **Увімкнути посилання Gradient** в налаштуваннях. На macOS її оголошує `Gradient Launcher.app`. Встановлення потребує підтвердження в картці проєкту.

У бібліотеці можна створити чистий профіль із релізною версією Minecraft, перейменувати його, змінити іконку, дублювати або видалити. У діалозі **Акаунти** можна переглядати збережені Minecraft-акаунти, обирати основний і видаляти непотрібні.

У **Скін Minecraft** можна застосувати PNG зі звичайною або тонкою моделлю рук чи повернути стандартний скін без плаща. Дії застосовуються до активного Minecraft-акаунта з доступом до онлайн-профілю.

У вкладці **Логи** можна перемикатися між живим виводом Minecraft, збереженими логами і звітами про збої. У **Налаштуваннях** можна задати максимальну пам’ять, роздільну здатність, повноекранний режим і аргументи JVM.

У **Інсталяціях Java** можна переглянути збережені шляхи, вибрати локальний виконуваний файл або завантажити Java 8, 17, 21 чи 25.

Для модів із Modrinth у вкладці **Контент** можна вибрати іншу сумісну версію. Для перерваних, невдалих і скасованих встановлень у **Завантаженнях** можна переглянути й скопіювати діагностичний звіт.

У вкладці **Скриншоти** можна переглянути знімки профілю та експортувати їх одним ZIP-архівом.
У вкладці **Файли** можна переглядати папки профілю, читати й редагувати доступні для запису UTF-8 файли до 256 КіБ та зберігати копії через системний діалог.

У меню профілю доступні експорт `.mrpack` з вибором вмісту, групи та перевизначення Java й пам’яті. У бібліотеці можна імпортувати профілі з Prism Launcher, MultiMC, ATLauncher, GDLauncher і CurseForge. Вкладка **Сервери** підтримує локальні записи профілю й запуск гри з підключенням до вибраного сервера.

Команда **Створити ярлик** у меню профілю зберігає `.url` на Windows або `.webloc` на macOS. Ярлик відкриває збережений профіль і пропонує запустити Minecraft. На macOS для цього використовуйте запакований `Gradient Launcher.app`, який реєструє схему посилань.

## Windows

Потрібні Rust із toolchain workspace, Java 17 для Gradle, Visual Studio з C++ Build Tools і Windows SDK, .NET 8 та компоненти збірки WinUI 3 / MSIX. Для Microsoft-входу потрібен WebView2 Runtime.

З кореня репозиторію в x64 Developer PowerShell:

```powershell
$env:SQLX_OFFLINE = 'true'
Push-Location core
cargo build --locked --release -p gradient-core
Pop-Location
MSBuild winui/Gradient.WinUI.csproj /restore /p:Platform=x64 /p:Configuration=Release
```

Запустіть `Gradient.WinUI.exe` із каталогу Release під `winui/bin`. Проєкт копіює зібране ядро поруч із застосунком. Для іншого розташування задайте абсолютний шлях до ядра через `GRADIENT_CORE`.

## macOS

Потрібні macOS 15+, Xcode 16+ зі Swift 6, Rust і Java 17 для Gradle. З кореня репозиторію:

```sh
root="$(pwd)"
cd "$root/core"
SQLX_OFFLINE=true cargo build --locked --release -p gradient-core
cd "$root/swiftui"
GRADIENT_CORE="$root/core/target/release/gradient-core" swift run Gradient
```

## GitHub Actions

Workflow **Build Gradient Native** запускається після push у `native/github-actions`. Після додавання workflow до default branch його також можна запускати вручну в **Actions → Build Gradient Native → Run workflow**.

У **Artifacts** будуть збірки для Windows x64, macOS Apple Silicon (`arm64`) і macOS Intel (`x86_64`). Для Windows розпакуйте весь архів і відкрийте `Gradient.WinUI.exe`. Для macOS 15+ розпакуйте `.tar.gz` для свого процесора й відкрийте `Gradient Launcher.app`. Це збірки для тестування. Для Windows потрібен .NET 8 Desktop Runtime, а для Microsoft-входу — WebView2 Runtime.

### Релізи й оновлення

Тег формату `native-vMAJOR.MINOR.PATCH` на перевіреному коміті запускає релізну збірку. GitHub Actions ставить версію з тегу у WinUI, SwiftUI та Rust-ядро, збирає пакети для трьох платформ і публікує один GitHub Release після завантаження всіх пакетів. Наприклад, для першого релізу, новішого за попередню збірку `0.1.0`:

```sh
git tag native-v0.1.1
git push gradient native-v0.1.1
```

У **Налаштуваннях → Перевірити оновлення** можна завантажити й встановити нову версію з перезапуском лаунчера. На Windows один раз встановіть Gradient через `*-Setup.exe` з GitHub Releases. На macOS один раз встановіть підписаний `Gradient Launcher.app` для своєї архітектури. Перед встановленням оновлення завершіть Minecraft і дочекайтеся завершення встановлення модпаків. Портативна Windows-збірка й непідписані macOS-збірки показують посилання для ручного завантаження.

Щоб увімкнути Sparkle для релізів, додайте `SPARKLE_PUBLIC_KEY` у GitHub Actions Variables і відповідний приватний ключ, експортований через `generate_keys -x`, у `SPARKLE_PRIVATE_KEY`. У GitHub Actions Secrets також додайте `MACOS_CERTIFICATE_BASE64` (Developer ID Application у форматі `.p12`, закодований у Base64), `MACOS_CERTIFICATE_PASSWORD`, `MACOS_NOTARY_KEY_BASE64` (ключ App Store Connect `.p8` у Base64), `MACOS_NOTARY_KEY_ID` і `MACOS_NOTARY_ISSUER`. Workflow підпише та нотаризує обидві macOS-збірки і додасть до релізу окремий підписаний appcast для кожної архітектури. Для перевірки встановіть перший підписаний реліз і перевірте оновлення після публікації другого.

Обидві оболонки приймають шлях до `.mrpack` як аргумент і пропонують імпортувати файл. Пакет macOS також оголошує підтримку `.mrpack` у Finder.

## Дані та протокол

За замовчуванням ядро відкриває окремий каталог `com.gradient.launcher.native`. Для перевірки на наявних профілях задайте `THESEUS_CONFIG_DIR` на копію каталогу даних Tauri. Якщо в налаштуваннях заданий зовнішній шлях до файлів профілів, скопіюйте їх і виправте шлях у тестових налаштуваннях перед запуском. Нативне блокування захищає від одночасного запису двома нативними клієнтами. При виході з оболонки ядро зберігає процеси гри й активні встановлення до їх завершення, а новий клієнт тієї ж бази зможе підключитися після виходу попереднього ядра.

Перший рядок stdout — `{"protocol":1}`. Далі оболонка надсилає по одному JSON-об’єкту на рядок. На кожну команду ядро повертає один рядок `{"ok":...}` або `{"error":"..."}`. Стан бібліотеки, черги й логів клієнти оновлюють опитуванням. Microsoft-вхід використовує OAuth-потік вихідної Tauri-версії, а WebView використовується для вікна входу.
